4Paradigm (Beijing Fourth Paradigm Intelligent Technology, HKEX 6682) is a Chinese enterprise AI company building decision-making and generative AI platforms — the Sage AIOS AI operating system, Sage HyperCycle ML/CV/OCR, SageGPT and the SageOne AI computing appliances — for banking, insurance, securities, retail, energy, healthcare and manufacturing. Its public, machine-readable API surface is published almost entirely through its open-source community at github.com/4paradigm: OpenMLDB, an Apache-2.0 machine-learning feature database with a documented REST APIServer, Protobuf/brpc cluster services and Java/Python/Go/C++ SDKs; OpenAIOS-Platform (Pineapple), a Kubernetes-based AI development platform that ships OpenAPI 3.0.3 contracts; and PhanthyMotus, an MCP-native embodied-AI agent framework whose hardware drivers are Model Context Protocol servers.

**Areas:** Company · Artificial Intelligence · Machine Learning · Feature Store · Database · Open Source · MLOps · Agents · Robotics · Kubernetes

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for 4Paradigm: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
